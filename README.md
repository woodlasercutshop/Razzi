# Beauty salon Razzi — запуск на GitHub

## 1. Выложите сайт на GitHub Pages
1. Откройте github.com и войдите в аккаунт.
2. Нажмите New repository.
3. Назовите репозиторий `razzi`.
4. Выберите Public.
5. Нажмите Create repository.
6. Нажмите Add file → Upload files.
7. Загрузите все файлы из этой папки, включая `.nojekyll`.
8. Нажмите Commit changes.
9. Откройте Settings → Pages.
10. В Branch выберите `main` и папку `/ (root)`.
11. Нажмите Save.
12. Подождите минуту.
13. Откройте ссылку `https://ВАШ-ЛОГИН.github.io/razzi/`.

## 2. Подключите облачную базу (Supabase, бесплатно)
1. Откройте supabase.com и создайте аккаунт.
2. Нажмите New project.
3. Откройте SQL Editor.
4. Вставьте содержимое файла `supabase.sql`.
5. Нажмите Run.
6. Откройте Project Settings → API.
7. Скопируйте Project URL.
8. Скопируйте ключ `anon public`.
9. Откройте файл `config.js` в репозитории GitHub.
10. Нажмите значок карандаша.
11. Вставьте URL и ключ между кавычками.
12. Нажмите Commit changes.
13. Подождите минуту и обновите страницу.

В кабинете мастера значок в шапке сменится с 💾 на ☁️. Это значит, что синхронизация работает.

## 3. Установка на телефон
1. Откройте ссылку в Chrome на Android.
2. Нажмите меню ⋮.
3. Выберите «Установить приложение».

## 4. Файл APK
1. Откройте pwabuilder.com.
2. Вставьте ссылку на сайт.
3. Нажмите Package for stores → Android.
4. Скачайте APK.

## Вход мастера
Логин: номер WhatsApp мастера. Пароль: последние 7 цифр номера.
Сразу смените их в Настройки → Админ мастера.

## Важно
Политика базы в `supabase.sql` открытая. Она подходит для пробного запуска.
Не размещайте ключ `service_role`. Используйте только `anon public`.
Перед платным запуском добавьте серверную проверку кода входа.
